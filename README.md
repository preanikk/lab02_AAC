«Ответы на контрольные вопросы»
1. Что такое IL и зачем он нужен между C# и машинным кодом? 
IL это промежуточный код который появляется после кмпиляции программы и нужен для того чтобы программа могла запускаться на любом процессоре
2. Почему .dll можно декомпилировать? 
Потому что сборка .net содержит IL и метаданные
3. Какие отличия Debug и Release вы увидели в IL? 
что release быстрее debug и в debug больше инструкций 
4. Почему Release обычно быстрее Debug? 
потому что release предназначен для готовой программы и более оптимизирован
5. Почему строковый пароль в .dll нельзя считать защищённым?
потому что сборку можно декомпилировать
